## C. 采用决策与后续

按清单内事前规则逐条判定：

1. 三成员 − V1 全年 **−0.001725 ≤ 0** → 不满足；且两个半年 ΔIC 均 ≈ −0.00172（低于 −0.001）→ 不满足。
   三成员 − TREE 亦为负 → **三成员未获时间确认支持**。
2. 转入回退检查：V1 − TREE 全年 **−0.004898 ≤ 0**，半年 −0.002311 / −0.007359 → **V1 也未获支持**。
3. 二者均不支持 → **保留既有已成功提交版本**（strong_baseline_v1 / ALT_v1 / TREE_v1 的既有身份不变），
   交负结果与全部证据，**不强行生成新推荐模型**，不据 2022 更换权重/seed/特征/选轮。

**审查 §6 指出的判定遗漏已修正**：首版判定代码只检查了三成员相对 V1 的半年门，漏了相对 TREE 的半年门。
用**已保存的四组合逐日分数**做算术核对（`v3_confirmation_tree_half_check.json`）：三成员 − TREE 半年为
**−0.004030 / −0.009090**，两个半年均低于 −0.001 → 该遗漏的检查**同样失败**，不改变"未获支持"的结论。
未为此重新打开 2022、未重跑模型、未搜索权重。

因此 C 板块按规则**不执行**最终全量拟合与新提交包：没有获支持对象可拟合；相应地本轮**没有"该包的 IC/IR"**可报告
（IR 只对最终冻结对象跑，本轮不存在这样的对象）。既有本地指纹（旧 TREE_v1 包、V1 夹具等）保持原身份，不转挂。
