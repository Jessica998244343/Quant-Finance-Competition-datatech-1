## 4. 三级判据核对（写死判据的逐条对照）

| 判据 | 结果 |
|---|---|
| 受影响股票日 <1% 且非系统性 | ✗ 系统性（每天 9–14% 行被剔除） |
| `|ΔIC| < 0.001`（2019、2020 分年） | ✓ 2019 −0.00030 / 2020 −0.00032（纯 P5）；融合 −0.00035 / −0.00047 |
| ΔIC 在 2019/2020 同号 | ✓ 均为负 |
| `|ΔIR| < 0.05` 且方向不变 | ✓ ΔIR = +0.027，净超额由 −12.04% 改善到 −11.70% |
| 候选排序不变 | ✓ 见上 |
| 目标主动权重差 <1e-6、拒单变化 ≤2% | ✗ **最大权重差 0.0687，9,626/145,806 行 >1e-6**；拒单变化 0.43%（IC/IR 判据满足） |

两条不满足 → **判为三级**，按预登记建立对齐缓存与 REF-aligned，并**分别**报告修复贡献与模型改进贡献。

**修复贡献（单独看）**：`ΔIC ≈ −0.0004`（2019–2020）、`ΔIR ≈ +0.03`，方向混合、量级在噪声内；
**对齐重训贡献**：`ΔIC ≈ −0.0020`、`ΔIR ≈ −0.85`（相对 REF-v1），即无收益、略偏负。
结论：**不存在被输入语义掩盖的隐藏收益**；对齐的意义是正确性与可复现性，不是性能。

## 5. IR 的主要问题（诊断表）

来源：`artifacts/stage2_ic_ir/diagnostics/diagnostics.json`。

**5.1 毛净分离（REF-v1，2019–2020）**

| 指标 | 主费用 | 零费用 |
|---|---|---|
| 年化超额 | −12.04% | +39.00% |
| 日均主动收益 | −3.75 bp | +10.26 bp |
| 跟踪误差 | 0.03466 | 0.03448 |
| IR | −3.47 | +11.31 |
| 负季度数 | 6/8 | 0/8 |

显式费用 9.36 bp/日（占 NAV），毛到净的日均差 14.0 bp，**差额中约 4.6 bp 来自成交路径、
拒单与估值时点**，不是静态费率。因此「零成本 CAGR − 净 CAGR」只能作方向参考，不能当精确费用归因。

**5.2 成本结构**：总费用 572,897（≈57% 初始资金/2 年）；印花税 282,147、佣金 279,455、其他 11,294；
79% 的佣金恰好等于 5 元最低档，40% 成交额 <1 万元，中位成交 13,166 元。拒单 467：现金不足 293、
停牌 124、跌停 40、涨停 10。

**5.3 换手与秩稳定**：日均双边换手 0.92；相邻日秩相关 0.38–0.43（三个成员都接近），
头部 10% 重合率仅 0.34，平均绝对秩变动约 70/300。

**5.4 优化器利用**：主动权重上限 ±0.01 **每天有 20.2% 的股票正好贴边**；主动份额 1.16；
单股权重最大 0.0886（未触 0.10）。

**5.5 头尾转化**：按目标权重分五组，H=1 收益从底部 0.046%/日单调升到顶部 0.234%/日
（多空差 0.189%/日），但组合只能把顶部组超配 +0.87%、其余四组各低配约 −0.22%，
主动贡献约 +2.1e-5/日。**IC 到 PnL 的损失主要来自「±1% 主动权重上限 + 长仓约束」的结构性截断**，
而不是排序方向错误。

**5.6 融合的角色**：融合把 IC 抬高约 +0.0011~0.0015，但在两个时期都把 IR 拉低
（dev −3.145→−3.473；2021 −3.371→−3.397），净超额也变差。即 CatBoost 成员在 IC 上有增量，
在**风控/配置层面是负贡献**。

## 6. 推荐的 B 两条路线

1. **路线一（优先）**：先做 5.1 的融合权重扫描 `{0, 0.125, 0.25, 0.5, 1}`（每个候选同时看 IC 与主成本 IR），
   再按 5.2 做「种子平均」与「慢/稳信息专家」（移除自构 `ret_1/ret_2/hl_range/close_pos/overnight/intraday`
   与官方 `daily_return/change_ratio`），慢专家只试两套容量、混合权重 a∈{0.1,0.2}。
   依据：纯 P5 在两个时期都优于融合的 IR；相邻日秩相关仅约 0.40；费用约等于毛 alpha。
2. **路线二**：5.3 的 H=1 收益幅度混合（`z_rank` 与稳健 `z_mag` 按 λ∈{0.1,0.25} 混合）。
   依据：头部与底部组的 H=1 收益差达 0.19%/日，而 ±1% 主动上限导致 20% 股票天天贴边，
   改善的排序**幅度信息**可能提升被截断仓位处的配置质量。

5.4 有限平滑**暂不启动**：它需要另训一个底层依赖 ≤61 日的辅助模型（v1 的 `ret_119` 已用满 120 日），
成本明显更高；若路线一显示抖动确实带来主要成本，再按预登记条件开启。
