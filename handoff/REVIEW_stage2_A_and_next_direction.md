## 2. 阻塞项：A 的新融合按整年排名

### 2.1 已核实事实

`src/qf3/s2_models.py:71–78` 的 `centered_rank` 不接收日期，只对传入数组整体排名。`src/qf3/s2_compare.py:68–95` 把整折全年 P5/CatBoost 原始预测传入它，生成 `origmodel_realinput` 和 `aligned_retrain` 的融合分数。

因此实际计算为整年股票日池中的成员排名再混合，而预定配方是**每个信号日、当日完整股票池内**的成员排名再混合。跨日期的分布变化会改变每日成员相对作用，且未来日期的分数参与了当前分数构造。它不是可以忽略的统一单调变换。

|---|---|---:|
| DEV19 | origmodel_realinput | 80.59% |
| DEV20 | origmodel_realinput | 79.47% |
| CONF21 | origmodel_realinput | 74.42% |
| DEV19 | aligned_retrain | 77.36% |
| DEV20 | aligned_retrain | 80.52% |
| CONF21 | aligned_retrain | 75.34% |

六组保存分数与整年排名公式的最大绝对差均约 `1.11e-16`，确认错误已进入产物，而不只是源码中的潜在风险。这里名次变化比例包含小幅变化，不应再解释成相同比例的大幅经济损失。

这些是实现正确性验收，不是重做全量原始数据审计。除非发现构造错误，不重建已经正确的整块缓存。

### 3.3 成本归因漏掉了直接滑点

原报告将约 4.6 bp/日差额归因于成交路径、拒单和估值时点，证据不成立。平台 `cost_model.py` 把滑点计入 `trade_value`，`total_cost` 只含佣金/税/其他显式费用。

对原 legacy REF-v1 的同一回测，主 Agent 从已有逐笔与净值文件复算：

| 项目 | 日均占 NAV |
|---|---:|
| 显式费用 `total_cost` | 9.36018 bp |
| 滑点 `abs(trade_value-position_value)` | 4.60486 bp |
| 两者合计 | 13.96504 bp |
| 零成本与主成本日均主动收益差 | 14.00946 bp |

此表沿用 A 诊断的**当日收盘组合价值**作分母，滑点累计约 282,360.62。两条回放的收益差与当日费用比例不是严格可加的收益恒等式，剩余约 0.04442 bp 也不能直接宣称全由某个单一机制导致；现金、持仓路径和分母时点仍要区分。

分析结论：在本地代理下，交易摩擦相对信号收益很重，值得优先研究；但报告所称的“大量未解释路径损失”主要是滑点漏项。不能据此调整主代理费用去贴近线上 IR。

最低佣金也应明确分母：79.08% 是触发 5 元佣金的**成交笔数比例**；这些成交占总佣金金额约 75.38%。40.15% 是成交金额低于 1 万元的**笔数比例**，不是金额占比。返修统一写清分母，并对正确真实输入参照重做必要诊断。

### 3.4 头尾、主动份额与贡献统计

- `s2_diagnostics.rank_stability` 对升序秩使用 `nsmallest`，所报 top10/top20 实际是**低分尾部**，而平台高分优先。保留尾部结果并更名，另算高分头部；共同池内重新排名或明确分母，不能继续称“头部每天换掉约 2/3”。
- `optimizer_use` 的 active_share 是 `sum(abs(w-b))`，缺少通常定义中的 1/2。原值 1.15855 应标为主动权重 L1；对应 Active Share 约 **0.57928**。贴约束比例目前是股票日行数比例，不是“每天都恰好 20.2%”。
- `head_tail_conversion` 按目标总权重分组，而不是预测分数；零目标权重的并列被 `rank(method='first')` 任意拆组。它不能直接回答模型高分端的预测质量。
- 所谓分组贡献 `mean((w-b)*future_return)` 是股票日平均，没有先在每个交易日对组内股票求和。报告的约 `2.1e-5/日` 不能解释成该组对组合每日收益的贡献。

返修分别给出分数头尾组、主动超低配组的有效样本数、日均收益和先逐日求和再跨日平均的贡献；明确 H=1 O2O 目标权重诊断与实际持仓/收盘净值归因的差别。不要用全池未覆盖的标签默默改变收益贡献分母。实际组合贡献若未完成，就明确缺失，撤回因果结论。

**撤回“IC 到 PnL 的损失主要由 ±1% 上限和长仓约束造成”的结论。** 目前只有约束占用和分层相关性证据，没有识别约束造成损失大小的对照。也不要为了证明该说法改优化器参数。

以下均为分析与条件计划，沿用 [第二阶段原任务书](Prompt_for_DS_stage2_IC_IR.md)，不因旧 A 数字而放宽晋级要求。

### B1：先做融合取舍，判断收益转化

正确同口径成员预测上扫描 CatBoost 权重 `{0, 0.125, 0.25, 0.5, 1}`。DEV19/20 开发，2021 只对少数保留者做稳健性复核。优先检查 0 和 0.125，但不预定纯 P5 获胜。

单看现有纯 P5 真实输入的 DEV19–20 结果，IC 约 0.07742、IR 约 -2.960，可作为复查锚点；它尚不能与错误新融合构成合法比较，更不能证明线上一定改善。该单模型仍继承旧训练归一化限制。

区分两种收益来源：减少错误配置与减少交易成本。旧 P5 换手不比融合低，不能把纯 P5 的历史 IR 优势解释成已经实现降成本。只有正确配对结果才能确定来源。

### B2：降低无收益的信号翻转，而不是单纯追求低换手

在 B1 后选定工作参照，先按原任务书做 P5 三固定种子平均；再做两个容量的弱化单日信息专家，混合权重只用 0.1/0.2。维持 H=1、每日输出、既定费用和约束，不改变评测交易机制。

金融分析：当交易摩擦接近或超过零成本主动收益，改善信号的持续性可能有价值；但短期反转也可能是真实收益来源。必须同时报告高分/低分稳定性、毛净收益、显式费用与滑点，确认减少的交易不是把有效 alpha 一起删掉。种子平均若无实际改善就停止，不为了模型数量继续增加成员。

### B3：小比例收益幅度目标，优先级次于前两步

沿用 H=1 下 λ∈{0.1,0.25} 的秩目标与稳健幅度目标混合；暂不额外扩容量网格。其可能价值是改变**学到的股票排序**与配置质量。锁定平台会将输出 score 排名，不能声称单纯扩大预测分数幅度就能绕过主动权重上限。

旧 A 的目标权重分组统计不是此路线的充分论据；只有正确头尾/主动贡献诊断或前两步不足时，才将有限预算分给它。

### 条件分支：有限平滑

待正确头尾稳定性与毛净配对证明存在值得处理的短暂翻转、且 B1/B2 不足时，再考虑原任务书的有限历史辅助模型。v1 已使用 120 个价格点，禁止直接拼接过去 3/5 天 v1 预测形成超过 120 日的总依赖。保留窗口内重算、无跨调用状态、同一固定模型重算历史各日和 CPU 验收要求。

### 共同晋级纪律

- 保持原任务书 IC 保护线、DEV 净超额提高至少 2 个百分点及 IR 争取提高 0.30 的目标；看年度差异、TE、成本和配对不确定性。2021 已参与选型，不能重新包装为盲测。
- 同时报告对 REF-corrected 和正确 v1 桥接的改善；仅胜过退化参照不算强候选。
- 只给少数入围者补 0/0.5/1/1.5 倍成本情景，不做全交叉搜索，不根据官方单次成绩反推隐藏费用或日期。
- 只有候选配方冻结后才进入 C 的 2022 时间确认；模型截止只能到 2021 合法标签。最终 CPU 包、普通静态导入、独立 train.py 复现及 1024 MB 限制仍按原任务书执行。
- 全部上传由用户完成；本次 A 返修不占线上额度，也不单独做通路提交。

## 7. 全局位置

当前仍在“第一阶段验收补充＋第二阶段问题定位”的 A 门槛。整场路线无需推翻：A 可信参照与诊断 → B 有限 IC/IR 改进 → C 冻结候选、时间确认与 CPU 包 → 用户官方反馈 → 再决策后续研究。

本次真正需要调整的是近期节奏：先修复影响结论的评价实现，再用可信结果分配模型研究预算。主线仍是保护现有 IC、提高实际净收益与 IR；不是为了让 A 报告通过而强行证明某个已提出的金融机制。
